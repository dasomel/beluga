# Contributor Covenant Code of Conduct

English | [한국어](CODE_OF_CONDUCT-ko.md)

## Our Pledge

We as members, contributors, and leaders pledge to make participation in this project a
harassment-free experience for everyone.

## Our Standards

- Demonstrating empathy and kindness toward others.
- Respecting differing viewpoints and constructive technical discussion.
- Focusing on what is best for the project and the wider open-source community.

## Enforcement

Report issues to the repository maintainer (see [SECURITY.md](SECURITY.md) for the
private reporting channel).
